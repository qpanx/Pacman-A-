Ghosts Game (Pac-Man-like)
This project is a Pac-Man-like game developed using Python and Pygame. The game features a player navigating through a maze while avoiding ghosts. The player can eat pellets to score points, and collect power-ups to turn the tables on the ghosts, making them vulnerable to being eaten.

Features:
Player Movement: The player can move in 4 directions using arrow keys.

Ghost AI: The ghosts follow specific behavior patterns, including random and targeting movements.

Power-ups: The player can collect power-ups that make the ghosts vulnerable.

Level Design: A custom maze layout with walls, pellets, and power-ups.

Collision Detection: Efficient collision checks between the player, walls, and ghosts.

Scoring System: Players earn points by eating pellets and ghosts when they're vulnerable.

Technologies Used:
Python: The main programming language used to develop the game.

Pygame: A library used for handling the game’s graphics, animations, and user interactions.

Mathematics: Various algorithms are used for the ghosts' AI and player movement (like Manhattan distance for pathfinding).
